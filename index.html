High Performance Computing · Team Project

• The brute-force approach scaled near-linearly to ~28× speedup on 80 cores (embarrassingly parallel), while divide-and-conquer plateaued at ~7.3× due to cross-boundary strip-exchange communication overhead, a tradeoff between asymptotic complexity and parallel scalability.

Loads LaMini-Flan-T5-77M, a 77-million-parameter encoder-decoder Transformer, quantized to 4-bit precision (~100 MB) and executed locally on CPU via ONNX Runtime Web. The prompt is structured as a multiple-choice question with five options (A-E). A custom logits processor intercepts the decoder's first-step output before sampling, capturing the full 32,000-token vocabulary distribution. Probabilities for the A-E token IDs are extracted, renormalized via Softmax, and rendered as a bar chart -- visualizing the model's internal confidence calibration across answer choices.
